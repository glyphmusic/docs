# Keyboard shortcuts

On macOS use `Cmd` wherever this page says `Ctrl`.

## Anywhere

| Keys | Does |
| --- | --- |
| `Ctrl+K` | focus search |
| `Ctrl+L` | show or hide lyrics |
| `Ctrl+1` … `Ctrl+9` | open the sidebar entries from top to bottom |
| `Ctrl+0` | open Settings |
| `Ctrl+Left` / `Ctrl+Right` | previous / next song |
| `Esc` | close the open dialog, menu or full-screen view |
| `Ctrl+Q` | quit |

## While no text field is focused

| Keys | Does |
| --- | --- |
| `Space` | play / pause |
| `Left` / `Right` | seek back / forward |
| `Up` / `Down` | move through the song list |
| `Enter` | play the selected song |
| `Delete` / `Backspace` | remove the selected song from the playlist or queue |

## A-B loop

Repeat one part of a song, for example to learn a passage.

| Keys | Does |
| --- | --- |
| `Alt+1` | set the loop start at the current position |
| `Alt+2` | set the loop end; playback jumps back to the start from here |
| `Alt+0` | turn the loop off |

## Text fields

The usual editing keys work: `Ctrl+A`, `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Home`,
`End` and `Shift+Left/Right` to select.

{% hint style="info" %}
Media keys and your system's play controls (Windows media overlay, macOS Now
Playing, Linux MPRIS) control Glyph too. See
[Integrations](../using-glyph/integrations.md).
{% endhint %}
