# Keyboard shortcuts

On macOS use `Cmd` wherever this page says `Ctrl`. **Settings › About ›
Shortcuts** lists every shortcut with the key it has on your computer.

## Change a shortcut

1. Open **Settings › About › Shortcuts** (or **Settings › Playback › Player ›
   Change shortcuts**).
2. Click the keys next to a shortcut. It shows *Press a key …*.
3. Press the new key, with `Ctrl`, `Alt` or `Shift` if you like.

* `Esc` cancels, `Delete` or `Backspace` removes the key: the shortcut then
  has none.
* If another shortcut had that key, it moves over and the other one has no key
  any more; Glyph says so.
* The keys under [Fixed keys](#fixed-keys) cannot be taken.
* A key without `Ctrl`, `Alt` or `Cmd` (a letter, `Space`, an arrow) never
  fires while you type in a text field.
* The arrow next to a changed shortcut puts its default back; **Reset all**
  resets every shortcut.

Shortcuts belong to this device: they are not synced or shared.

## Playback

| Default | Does |
| --- | --- |
| `Space` | play / pause |
| `Left` / `Right` | seek back / forward 5 seconds |
| `Ctrl+Left` / `Ctrl+Right` | previous / next song |
| `Ctrl+Up` / `Ctrl+Down` | volume up / down |
| `M` | mute / unmute |
| `Ctrl+Shift+L` | like the playing song |
| `Ctrl+S` | shuffle on / off |
| `Ctrl+R` | repeat: off, all, one |
| `Ctrl+D` | download the playing song |
| `Alt+1` | A-B loop: set the start at the current position |
| `Alt+2` | A-B loop: set the end; playback jumps back to the start from here |
| `Alt+0` | A-B loop off |

The A-B loop repeats one part of a song, for example to learn a passage.

## Navigation

| Default | Does |
| --- | --- |
| `Ctrl+K` | focus search |
| `Ctrl+L` | open Now Playing, or show / hide the lyrics there |
| `Z` | [zen mode](../using-glyph/now-playing.md#views): only the cover and the player bar |
| `Ctrl+J` | show / hide the queue |
| `Ctrl+0` | open Settings |

## App

| Default | Does |
| --- | --- |
| `Ctrl+Q` | quit |

## Fixed keys

| Keys | Does |
| --- | --- |
| `Up` / `Down` | move through the song list |
| `Enter` | play the selected song |
| `Delete` / `Backspace` | remove the selected song from the playlist or queue |
| `Ctrl+1` … `Ctrl+9` | open the sidebar entries from top to bottom |
| `Esc` | close the open dialog, menu, zen mode or full-screen view |

Keys without `Ctrl`, `Alt` or `Cmd` only work while no text field is focused.

## Mouse

| Gesture | Does |
| --- | --- |
| Wheel over the seek bar | jump forward (up) or back (down), 5 seconds per notch |
| Wheel over the volume | louder (up) or quieter (down), 5 % per notch |
| Right-click a player button | more options, see [First steps](first-steps.md#handy-controls) |

Change the wheel steps, or switch them off, under **Settings › Playback ›
Player**.

## Text fields

The usual editing keys work: `Ctrl+A`, `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Ctrl+Z`,
`Home`, `End` and `Shift+Left/Right` to select.

{% hint style="info" %}
Media keys and your system's play controls (Windows media overlay, macOS Now
Playing, Linux MPRIS) control Glyph too. See
[Integrations](../using-glyph/integrations.md).
{% endhint %}
