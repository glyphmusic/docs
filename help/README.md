# Help

Pick the area that is not working. Every page starts with the message Glyph
shows, then the steps that fix it, quickest first.

| Problem | Page |

| Cannot join a Jam, out of sync, *Not available for you*, *Host offline* | [Jam](jam.md) |

| Your own server, the companion, AI assistants | [Your own server](server.md) |

## First, try these

1. **Check the server.** **Settings › Server** shows whether the server answers.
   Most "nothing works" problems are a server that is not reachable.
2. **Restart Glyph.** Running [transfers](../using-glyph/transfer-music.md)
   continue after a restart.
3. **Update.** **Settings › About** shows whether a newer version exists. Many
   problems with YouTube or a server are fixed there.

## Glyph uses a lot of disk space

**Settings › Cache & Storage** shows what takes space and clears covers, lyrics,
the stream cache and search data. A *Cache size limit* removes old files
automatically. Downloads are never removed by the limit.

## Still stuck?

**Settings › Support › Copy diagnostic info** copies version and system details
without keys or personal data. Paste it into a
[GitHub issue](https://github.com/glyphmusic/apps/issues/new) together with what
you did and what you expected.
