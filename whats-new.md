# What's new

Every release of every part of Glyph (the desktop, Android and web apps, the
server and CLI, the companion and r-dlp) is listed newest first at
**[glyph.my/changelog](https://glyph.my/changelog)**. You can filter it by part.

Each repository also keeps its own `CHANGELOG.md`:

* [Apps (desktop, Android, web)](https://github.com/glyphmusic/apps/blob/main/CHANGELOG.md)
* [Server and CLI](https://github.com/glyphmusic/server/blob/main/CHANGELOG.md)
* [Companion](https://github.com/glyphmusic/companion/blob/main/CHANGELOG.md)
* [r-dlp](https://github.com/glyphmusic/r-dlp/blob/main/CHANGELOG.md)
