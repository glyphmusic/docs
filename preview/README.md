# Docs preview

Shows these docs locally the way docs.glyph.my renders them, with the server's
real page template. Needs Node.js 18+ and a glyph-server checkout next to this
repository (or `GLYPH_SERVER=/path/to/glyph-server`).

```bash
cd preview
npm install
npm start          # http://127.0.0.1:4000, reload after editing a page
```
