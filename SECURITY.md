# Security policy

This repository holds the Markdown documentation served on
[docs.glyph.my](https://docs.glyph.my).

## Reporting a vulnerability

Do **not** open a public issue or pull request for a security vulnerability in
Glyph. Report it privately through GitHub Security Advisories on the affected
repository (or here if you are unsure which repository applies):

- **Desktop and Android app (`glyphmusic/apps`):** [Report an advisory](https://github.com/glyphmusic/apps/security/advisories/new)
- **Server, `glyph.my` and `docs.glyph.my` (`glyphmusic/server`):** [Report an advisory](https://github.com/glyphmusic/server/security/advisories/new)
- **Plugin catalog and validator (`glyphmusic/plugins`):** [Report an advisory](https://github.com/glyphmusic/plugins/security/advisories/new)
- **YouTube audio resolver (`glyphmusic/r-dlp`):** [Report an advisory](https://github.com/glyphmusic/r-dlp/security/advisories/new)
- **Companion service (`glyphmusic/companion`):** [Report an advisory](https://github.com/glyphmusic/companion/security/advisories/new)
- **Documentation (`glyphmusic/docs`):** [Report an advisory](https://github.com/glyphmusic/docs/security/advisories/new)

You can also use the contact in
[glyph.my/.well-known/security.txt](https://glyph.my/.well-known/security.txt).
